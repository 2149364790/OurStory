# 💖 CoupleSpace | 两人的专属私密空间

`CoupleSpace` 是一款专为情侣/伴侣量身打造的高颜值、私密互动手账式 Web 应用。基于 React + TypeScript + Supabase 构建，集成了恋爱计时、打卡记录、心事倾诉、约定日协商以及伴侣专属生活小百科等功能，并支持实时数据同步与推送，为你们的情感升温保驾护航。

---

## 🌟 核心功能模块

### 1. 相伴时间与温馨主页 🌅
* **高颜值拟物化计时器**：精确到秒记录你们相伴的时光。
* **动态氛围主题**：支持三种沉浸式视觉主题——**温暖落日 🌅**、**浪漫星空 🌌** 与 **烂漫樱花 🌸**（带樱花飘落动效），亦可随当前时间自动切换。
* **爱意回赠组件**：一键向远处的 Ta 隔空发送拥抱 🤗、飞吻 💋、摸摸头 💆‍♂️ 或思念 👀，对方会收到实时屏幕撒花特效及设备震动反馈。
* **每日情话**：内置并支持添加双人专属的甜蜜情话，支持双击一键复制，让爱意融入日常。

### 2. 恋爱 100 件事清单 📋
* **里程碑打卡**：精美卡片化展示恋爱必做小事，记录你们共同完成的每个第一次。
* **打卡日记**：完成打卡时支持上传照片、记录甜蜜感言，生成两人的时光回忆河流。

### 3. 心事箱 (Whispers) 💬
* **悄悄话信箱**：有些不好意思当面说的话，或者是小摩擦后的心里话，可以投递到心事箱中。
* **支持语音留言**：支持录制并发送温馨的语音悄悄话。
* **只读透明提醒**：对方未读时会有气泡提醒，确保每份心意都有回音。

### 4. 约定日复盘 (Monthly Review) 📅
* **沟通复盘房间**：每月固定时间或提议时间，双方共同进入沟通复盘页。
* **双盲提交机制**：双方独立填写本月相处的闪光点、摩擦点与改进建议，在双方都提交前内容互不可见，保障坦诚和独立的思考。
* **达成一致后解除屏蔽**：双方提交后即可揭晓彼此的心声，帮助情侣建立健康的沟通习惯。

### 5. 伴侣百科与浪漫档案 (Partner Wiki) 🔍 `[NEW]`
* **实用信息卡**：记录彼此的衣服、裤子、鞋子尺码以及手指戒圈号（买惊喜礼物必备），还有奶茶专区喜好偏好、忌口与严重过敏源（点外卖神器），支持一键复制。
* **浪漫备忘卡**：记录对方的 MBTI 性格类型、当 Ta 难过/生气时的“哄 Ta 说明书”。
* **优点夸夸墙**：随时为对方写下一行赞赏，添加优点时屏幕绽放爱心礼花，并且伴侣端会实时弹出全局甜蜜通知。
* **惊喜心愿单**：公开彼此想要的心愿，或创建“仅自己可见”的私密礼物备忘，准备送出后勾选“达成”，收获惊喜与感动。

## 🛠️ 技术栈

* **前端框架**：React 18 + TypeScript + Vite
* **样式与动效**：Vanilla CSS + Tailwind CSS (毛玻璃、渐变、手账拟物化样式)
* **图标库**：Lucide React
* **特效支持**：Canvas Confetti (撒花/心形粒子特效)
* **后端/数据库**：Supabase
  * **Auth**：安全的用户登录和账户空间绑定。
  * **Database**：结构化数据存储与外键级联。
  * **Realtime Subscription**：极速的 PostgreSQL 变更广播（互动特效、夸夸通知和心事提醒的即时同步）。
  * **Storage**：云端存储情侣头像、打卡图片及语音文件。

## 🚀 快速开始

### 1. 克隆与配置

克隆项目到本地，在项目根目录下创建一个 `.env` 配置文件（请参考配置规范，不要提交该文件到公共 Git 仓库）：

```env
VITE_SUPABASE_URL=您的Supabase项目URL
VITE_SUPABASE_ANON_KEY=您的Supabase公钥
VITE_VAPID_PUBLIC_KEY=您的系统通知推送公钥(可选)
```

### 2. 部署 Supabase 数据库

登录您的 [Supabase 控制台](https://supabase.com)，在项目的 **SQL Editor** 中依次执行以下文件夹中的 SQL 迁移脚本：

1. **[supabase/schema.sql](file:///d:/TMEP/健身-饮食-护肤-穿搭-情绪-生活/our_story/supabase/schema.sql)**：基础核心表（包含 profiles 用户表、couple_config 基础配置表、tasks 任务表、whispers 心事箱表、monthly_reviews 约定复盘表、interactions 实时互动表以及存储桶配置）。
2. **[supabase/partner_wiki_schema.sql](file:///d:/TMEP/健身-饮食-护肤-穿搭-情绪-生活/our_story/supabase/partner_wiki_schema.sql)**：百科扩展表（创建 partner_preferences 尺码喜好表、partner_records 优点心愿表并注册实时同步流）。
3. (如果存在) 执行其他迁移文件来追加额外字段。

### 3. 安装并运行

在项目根目录下打开终端，执行以下命令：

```bash
# 安装依赖
npm install

# 本地开发环境运行
npm run dev

# 编译打包生产版本
npm run build
```

访问终端输出的本地开发地址（通常是 `http://localhost:5173` 或类似端口）即可开始使用！

## 🔒 隐私与安全性规范

为了保护您与伴侣的隐私：
* **`.env` 已加入忽略**：包含 Supabase 连接密钥的本地配置文件不会被提交至 GitHub。
* **Supabase 安全策略 (RLS)**：数据库表均配置了行级安全策略（Row Level Security），仅限经过身份验证的情侣用户对其数据进行操作。
* **惊喜礼物防剧透**：惊喜心愿单中勾选“私密惊喜”的数据，在对方端会被强制过滤屏蔽，不用担心惊喜提前泄密。
